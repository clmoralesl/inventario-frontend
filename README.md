Barlacteo FrontendEste proyecto es una aplicación frontend desarrollada en React diseñada para modernizar el sistema de Barlacteo, proporcionando una interfaz de usuario intuitiva y eficiente para interactuar con dos microservicios backend desarrollados en Spring Boot con Maven y API REST. El objetivo es mejorar la experiencia de los trabajadores y usuarios de Barlacteo, optimizando la gestión de inventarios y la autenticación segura.Los microservicios son:Microservicio de Inventario: Permite registrar y gestionar productos, lotes, movimientos, categorías y otras funcionalidades relacionadas con el control de inventarios.
Microservicio de Autenticación: Administra el registro de usuarios y restringe el acceso mediante tokens JWT, garantizando seguridad en el sistema.
